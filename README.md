# YiChat 译聊

![version](https://img.shields.io/badge/version-3.5.0-blue)
![electron](https://img.shields.io/badge/Electron-44-47848f)
![platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS-lightgrey)

**多平台聚合聊天 + 实时翻译桌面应用。**

把 18 个海外社交平台的会话聚合到一个工作台里，收发消息自动翻译。做跨境生意、海外客服、跨国沟通，不用再开十几个网页来回切换，也不用复制消息去翻译软件里翻完再粘回来——在 YiChat 里，看到的即是译文，发出的即是外文。

---

## 功能详解

### 1. 平台聚合

一个左栏装下全部平台账号，点开即聊：

WhatsApp、Telegram、Line、Facebook、Instagram、Messenger、X、TikTok、Zalo、Signal、Snapchat、Google Voice、TextNow、Google Messages、Line Business、Meta Business、Chrome、Google Chat，共 **18 个平台**。

- 每个平台用独立的会话分区（partition）隔离登录态，互不串号；
- 登录走各平台官方网页，本应用不经手你的账号密码；
- 左栏图标带在线绿点与未读角标，哪个号有新消息一眼可见；
- 「会话置于顶部」可把当前会话列表钉在顺手的位置。

### 2. 翻译系统

这是 YiChat 的核心。发送和接收是两条完全独立的翻译管线，各自可配：

- **翻译通道**：谷歌翻译 / 大模型翻译，可按需切换；
- **源语言**：自动识别或手动指定；**目标语言**：各平台、各方向分别设置；
- **三级优先级**：会话级 > 平台独立配置 > 全局配置。重要客户单独配，普通会话走全局，一处设置、处处生效；
- **全局模式 / 独立模式**：全局模式下所有平台共用一套设置，改一处同步全部；独立模式下每个平台单独一套，互不影响；
- **发送自动翻译**：输入中文，发出时自动变成对方的语言；
- **接收自动翻译**：对方的外文消息自动译成中文，译文以浅蓝色卡片贴在原消息下方（带蓝色竖线标记），原文译文对照着看；
- **翻译预览**：发送前在输入框上方先看一眼译文，确认无误再发；
- **防误发保护**：可开启「禁止发送含中文的消息」与「禁止发送含中文的翻译」两道拦截——译文里混进了中文会被直接拦下，避免把没翻干净的话发给客户（设置页里这两项带有橙色「谨慎」标记，提醒不要误开）；
- **代理路由**：谷歌翻译走账号自身的会话代理、全局代理仅作兜底；大模型 / API 国内直连，不绕路。

### 3. 首页工作台

打开应用的第一屏就是全天的工作总览，不是空白的平台列表：

- **问候区**：按时段变色的问候语（晨 / 午 / 下午 / 晚 / 夜各有配色），附日期时间、在线会话数；
- **三项核心指标**：今日翻译条数、今日成功率（带健康档位色：≥99% 绿色、<95% 红色，出问题一眼看见）、未读消息数，数字变化时滚动呈现；
- **快捷入口**：翻译设置、代理设置、API Key 管理、平台设置、性能监控、重置清零六个入口，支持编辑模式——拖拽排序、隐藏不用的、随时恢复；
- **近 7 天翻译柱状图**：每日条数一目了然，带日均虚线、悬停看某日明细，全 0 时有空状态提示；
- **平台状态卡**：已打开的平台置顶，带分隔线区分开 / 关；
- **未读待办卡**：哪个平台、哪个会话有未读直接列出，点一下直达；没有未读时卡片自动瘦身不占地方；
- **翻译节点卡**：当天真实翻译的平均延迟与档位评级（优秀 / 良好 / 偏慢 / 暂无数据）——统计来自每一次真实翻译的计时上报，不是测速 ping；
- **今日目标进度环**：自设每日翻译目标（100 / 200 / 300 / 500 / 1000 条点按切换），达标有庆祝标记，超额会显示超出条数；
- **命令面板**：`Ctrl + K` 全局搜索平台、功能、未读会话，键盘直达；
- **主题**：蓝 / 紫 / 青 / 橙四种主题色整页贯通（含图表、徽标、按钮），另有完整的深色模式。

### 4. 会话页增强

- **速用键工具栏**：最新消息直达、译文开关、截图、AI 帮写，四键贴在会话右侧；
- **话术库**：常用话术一键插入或直接发送，多客户同话术不用反复打字；
- **语音转文字**：语音消息转成文字再翻译，听不懂的语音也能处理；
- **未读角标与新消息提醒**：角标弹跳、未读卡闪烁，新消息不漏看；
- **会话页缩放**：按账号保存的界面缩放比例，换号不乱。

### 5. AI 帮写

不知道怎么回外文消息时，让 AI 代笔：

- 7 种语言 × 4 种语气（正式 / 友好 / 简洁 / 热情）组合生成回复；
- 生成后**自动回译成中文**给你核对，确认意思没跑偏再填入输入框发送；
- 需要自备大模型 API Key（在「API Key 管理」里添加），Key 只存在你本机；
- 入口有三处：首页顶栏按钮、会话页速用键、命令面板。

### 6. 数据统计与性能监控

- **本机统计**：今日翻译量、成功率、失败数、近 7 天趋势、节点平均延迟，全部由本机每一次真实翻译累加，**数据只存本机、不上传**；
- **性能监控页**：主机负载总览与健康分，内存 / CPU 占用与阈值告警、告警记录，负载过高时自动拦截继续开窗，保护机器和账号环境。

### 7. 设置

五个设置页，统一的卡片化界面与字体：

- **翻译设置**：按平台逐个配置（平台列表带搜索框，18 个平台输名字即达），发送 / 接收两组设置各自成卡，「应用」按钮吸底常驻——改完不用滚到页面底部找保存；
- **显示设置**：界面语言、缩放等；
- **API Key 管理**：大模型 Key 的增删管理；
- **平台设置**：18 个平台的启用与管理；
- **性能监控**：见上。

## 技术架构

| 层 | 说明 |
| --- | --- |
| 壳 | Electron 44，Windows 与 macOS（Apple 芯片）双平台 |
| 前端 | React + Ant Design 打包产物，平台会话以 webview 承载 |
| 主进程 | `src/main.js`：窗口与平台会话管理、统计落盘、IPC |
| 桥 | `src/preload.js`：向渲染层暴露受控 API |
| 大模型 | `src/llm.js`：多通道大模型调用（翻译 / AI 帮写） |
| 译文层 | `translate-overlay.js`：向平台页面注入译文卡片与计时上报 |
| 适配器 | `src/adapters/`：各平台会话状态、列表与连接适配 |
| 增强层 | `yichat-ui-tweak.js`：工作台首页、命令面板、速用键、话术库、AI 帮写抽屉等全部界面增强，以外挂脚本形式叠加在应用本体之上，不侵入原有逻辑 |

## 补丁脚本说明

这棵树是在发布版应用之上的修复与增强合集，根目录的补丁脚本记录了每一处对应用本体的定点修复，均可单独审阅：

- **patch-chrome.js**：修复平台挂载缺陷（18 个平台中有 2 个点入空白的问题）；
- **patch-lang.js**：修复界面语言切换时全局语言包被写死的问题，登录页误导文案一并修正；
- **patch-ui.js**：把顶栏节点状态与数据统计页从演示假数据换成真实统计接口；
- **patch-ui2.js**：为节点状态补「暂无数据」档，无数据时如实显示、不挂假值；
- **patch-ui3.js**：统一顶栏与节点卡的档位文案（优秀 / 良好 / 偏慢）。

## 运行方式

本仓库是**解包后的应用文件树**（与正式发布的 Windows / macOS 安装包内容一致），不是带构建流程的工程源码，没有 `npm run build` 一说。运行方式是把整棵树打包为 `app.asar`，放入对应平台的 Electron 44 运行时壳的 `resources/` 目录后启动。

## 数据与隐私

- 平台账号的登录、凭据均由各平台官方网页处理，本应用不收集、不上传；
- 翻译与使用统计只存放在本机；
- AI 帮写所用的大模型 API Key 只存放在本机，由使用者自行添加。
