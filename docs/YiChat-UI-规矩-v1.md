# YiChat 界面规矩 v1

2026-11-20 定。目的：以后任何新功能、任何改动，都照这页执行，不再各长各的。
数值以现有程序里占多数的值为准（已核对编译样式），少数不一致的列在最后「待对齐」里，留到第 5 步统一扫。

## 1. 颜色

- 主色只有一个：蓝 `#005dff`（主题色可切换紫/青/橙，但同一时刻只用一个主色）。
- 状态色只许三个：绿 `#389e0d` 系＝正常／已打开；橙 `#d46b08` 系＝提醒；红 `#d4380d` 系＝出错／未配置。
- 选中态：浅灰底 `#f0f0f0` ＋深灰字 `#262626`，不许用蓝底蓝字（2026-11-20 用户定）。
- 文字三档：主文字 `--wb-t1`、次文字 `--wb-t2`、小字说明 `--wb-t3`，新界面一律用变量，不写死颜色。
- 新功能不许自带新颜色；确实需要，先改这页规矩。

## 2. 按钮

只许三种规格：

- 主按钮：主色底＋白字，每页最多一个（例：设置页的「应用」）。
- 次按钮：白底＋描边 `1px rgba(0,0,0,.14)`＋深灰字（例：「✕ 关闭设置」改版后的样式）。
- 文字按钮：无底无边，只用在卡片头、行尾等次要位置（例：「折叠」「编辑」）。

统一：圆角 8px；高 32px（小号 26px）；字号 13px。
工具型小钮（如聊天里的「转文字」「看图」）是例外规格：字号 11px、圆角 10px、中性灰，不得用主色描边。

## 3. 卡片

- 结构固定：标题行（标题 13.5px 半粗 ＋ 右侧小字 11.5px）＋ 内容区。
- 圆角、内边距、底色用工作台现行 `--wb-*` 变量，新卡片直接套 `.yc3-card`，不自创。
- 卡内列表行：字号 13px，行上下间距 6px，左标签用次文字色、右值用主文字色半粗。
- 同一栏里的卡片间距统一（`--wb-gap`），不许一张贴一张。

## 4. 字号（只许五档）

- 20px：页面大标题（如问候语）。
- 13.5px：卡片标题。
- 13px：正文、列表行、按钮。
- 11.5–12px：小字说明、时间、角标。
- 22–30px：大数字（统计值），必须用等宽数字（tabular-nums），全页同一类数字只用一个尺寸。

## 5. 间距

- 只用 4 的倍数：4 / 8 / 12 / 16 / 24。不出现 5px、7px、13px 这类随手值。
- 卡片之间、区块之间用大间距（16/24）；卡内元素之间用小间距（8/12）。

## 6. 反馈三态（格式先定，第 3 步全面落地）

- 任何操作必须有三态：进行中（按钮文案变「…中」或转圈）／成功（轻提示或直接呈现结果）／失败。
- 失败文案固定格式：**人话原因 ＋ 下一步点哪里**。禁止把接口原文报错直接给使用者看（反例：「ASR requires input_audio」；正例：「选错 Key 了：这是语音识别模型，翻译请改选小米看图那条」）。
- 危险操作（删除、清空、重置）必须二次确认，且按钮用红字不用红底大按钮吓人。

## 待对齐清单（第 5 步统一扫，先记录不马上改）

- 主页头部三个大数字是 22px、节点卡大数字是 30px，同类数字两个尺寸，待统一。
- 设置页开关、单选等控件的蓝色为程序自带样式，未纳入本规矩（动它要改编译样式，单独立项）。
- 聊天页（各平台 webview 内）由平台自身样式决定，本规矩只管我们注入的按钮和译文：译文格式 C（分隔线式）已是定版，注入按钮照第 2 条工具型小钮规格。
